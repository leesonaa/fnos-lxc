LXC 初始化向导

使用原生 LXC。按步骤完成后进入管理界面。

1. 安装软件包
2. 存储路径
3. 网络桥接
4. 完成

安装原生 LXC

将通过 apt 安装 lxc、lxc-templates、lxcfs 等（需 root，可能需几分钟）。

选择容器存储路径

不要放在系统盘。建议数据卷，例如 /vol1/1000/lxc。

网络桥接

飞牛请先在「网络设置」开启网卡 OVS。选择 *-ovs 桥，容器将以 veth 挂到该桥。

初始化完成

LXC 已就绪，可以创建和管理容器了。

添加容器

      

        
        
      

      

        
        
      

      

        

          
          
        

        

          
          
        

        

        

        
支持 .tar / .tar.gz / .tar.xz / .tar.zst / .tar.bz2 / .squashfs（如 NixOS 只发布 rootfs.squashfs）。必须是带 init 的完整系统 rootfs，且架构与本机一致（LXC 不能运行异构架构）；Docker 镜像导出的包通常无法启动。压缩包需来自可信来源。

      

      

      

        
        
      

      

        
        
      

      

        
        
      

      

      

        
        
        

      

      

        
        
        

        
NixOS 等对权限位严格的系统，在 fnOS 的 Btrfs 卷上构建会被拒绝（trimacl 不遵循 umask），请选 ext4 镜像。之后可在「更多 → 扩容」增大。

      

      

        
      

      
首次创建会从 images.linuxcontainers.org 下载模板，可能较慢。创建完成后会自动打开配置页（可设置 TUN、Docker、静态 IP 等）。
